# Open issues — the knowledge tool

What is outstanding about `knowledge` itself: the walk, the core's checks and its commands. What
is outstanding about the rules extension, the corpus and its releases is
`path@rules-corpus@docs/open-issues/`, and about the _rules and their readings_
`path@thaum@docs/rules/`.

**Read the entries before concluding that a checker behaviour is a new problem.** One file per
entry, its kind in the frontmatter, and the listing beside this file is generated. **An entry
leaves when it closes.**

Read `tracking-open-issues` before adding.
