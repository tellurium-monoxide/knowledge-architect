# Whether a census of a project's own text under a planned instruction is real use, or a run the workflow refuses

## Summary

`design@agent-skills@synthetic-evidence-not-built` refuses a run built to observe how an agent
follows the workflow's instructions, to choose between shapes among other purposes. In the design
discussion on what enters agent-facing text, subagents applied a proposed need test to this
repository's own agent-facing text three times, and their agreement counts shaped the test's
readings. The design-conformance review read that census as such a run; the owner read it as real
use, a run over a real project under an instruction the project plans to add, while holding the
point open to discussion. Which is it?

## Details

### What

The census ran independent read-only agents, two per part of the text, each listing the statements
that fail the test. The session compared what the two agents of a part flagged, and refined the
test's readings on the count; the owner then reopened the readings on the argument that the test's
aim is to strip what is not needed, not to make two readers agree. The decisions recorded rest on
arguments and the owner's word, and on no count of the census, so the question decides no built
shape. Not established: how the head's "a run is admitted only when its verdict reproduces" applies
to such a census.

### Why it matters

`goal@knowledge-architect@the-workflow-improves-through-real-use` defines real use as a session
applying the workflow in a real project, under supervision. A census over real text fits that
definition in part and a run built to observe agents in part. Until the reading is settled, a later
session cannot tell whether a census of the same kind may support the choice of a shape.

### What would close it

A reading of `design@agent-skills@synthetic-evidence-not-built` and the goal that states whether
such a census is admitted, and for what; recorded in the head by the owner's word, since the goal is
the owner's.
