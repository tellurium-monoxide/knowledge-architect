# The next run of the agentic-workflow audit repairs by cause, and starts from pass 3's open findings

## Summary

The first run of `skill@knowledge-architect-project-audit@agentic-workflow-axis` on this repository
stopped after pass 3, on the agent's proposal, which the owner approved. Its three passes repaired findings one site at a
time, and about 25 of pass 3's findings were interactions between the rules passes 1 and 2 had
added. The owner ruled that the axis repairs by cause instead, centralizes the instructions of one
moment in one home, and runs a second phase of agents that cluster findings and propose repairs.
The next run applies that method. This entry holds its inputs: the work the owner named, and the
findings pass 3 left without an outcome, grouped by the cause the session read in them. The groups
are a starting point for the cluster phase, not its result.

### Why it matters

`goal@agent-skills@one-skill-per-activity` is met while no two installed instructions are found that
a session cannot both obey, and `goal@agent-skills@installed-text-leaves-room-to-judge` while a
conflict a structure causes is answered by removing structure. The run measured the cost of the
opposite: local repairs that add rules produced interactions at the next pass, per
`design@agent-skills@capabilities-not-structure`.

### What would close it

these findings and its own by cause, repairs each cause, delivers the moment homes the owner ruled
on, and revisits pass 2's additions.
